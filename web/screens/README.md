# Экраны-макеты

Полноэкранные макеты страниц из компонентов кита: раздел Storybook «Экраны». Только Storybook: ни роутинга, ни API, ни новых продуктовых компонентов. Импорт — только из публичных API (`~/shared/ui/<группа>`, `~/widgets/<slice>`, `~/shared/lib/*`).

## Как написать экран

1. Файл `web/screens/<id>-<имя>/<Имя>.stories.tsx`, `title: "Экраны/S2 Карточка пакета"`.
2. Оберните содержимое в `ScreenFrame` из `../frame/ScreenFrame`: `active` — id пункта сайдбара, `breadcrumbs={{ trail, current }}`, `banners` — по необходимости.
3. `parameters: screenParameters` и `globals: desktop` / `mobile` из `../frame/screen`. Тёмная тема — `globals: { ...desktop, theme: "dark" }`.
4. Данные плотные и реалистичные (длинные имена, 40+ строк, кириллица вместе с латиницей, хэши, версии 2026 года); общие — в `web/screens/data/common.ts`.
5. Доменного блока волны 2 ещё нет — соберите его в story из молекул кита и пометьте:
   `// Спека волны 2: <паттерн §N> — будущий <слой/компонент>`.
6. Axe проверяет весь `body` и валит story-тест: ошибки правьте в компоненте или макете, не отключайте правило.

Экраны реагируют на тулбары «Тема», «Язык» и «Движение».

## Тексты (i18n)

Тексты интерфейса экранов пишутся макросом ``t`…` `` (и `plural`) из `@lingui/core/macro`. Форма ``t`…` `` актуальна: устарела только перегрузка `t(i18n)`, но type-aware Biome помечает весь импорт, поэтому в файле экрана стоит `// biome-ignore-all lint/suspicious/noDeprecatedImports` с причиной. Макрос берёт активную локаль в момент вызова, поэтому данные с текстами задаются **фабриками** (`function segments() { return [...]; }`), которые вызываются при рендере, а не константами и геттерами уровня модуля: `t` при загрузке файла упал бы без локали. Числа и даты форматирует `useTextFormat()`, а в ячейках таблиц и фабриках, где хука нет, — `activeFormat()` из `../frame/format`. Подписи состояний и решений — один словарь на enum (`data/states.ts`: тон и `msg`), а не строки в данных.

Контент витрины (имена пакетов, ФИО, описания, события журнала) остаётся русским: его объявление помечается строкой `// i18n-fixture: причина`, файлы `data/**` линтер проверяет как остальные. Для каждого экрана есть EN-story (`globals: { locale: "en" }`).

## Каталог экранов и перенос в приложение

Тексты макетов лежат в своём каталоге `screens/locales` и в бандл приложения не попадают. Когда экран переносится из макета в `src/pages`, каталог экранов удаляется вместе с макетом, а переносимые строки переходят в каталог приложения (`src/shared/lib/i18n/locales`): иначе `lingui check sync` держал бы два перевода одной фразы.
