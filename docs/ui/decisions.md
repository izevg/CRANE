# Решения по макетам и открытые вопросы

Вердикт владельца по пачке Stitch — «чепуха вперемешку с гениальностью». Здесь каждая заметная идея макетов разобрана: **оставить**, **адаптировать** или **отклонить**, с причиной. Стилистика (цвета, шрифты, тени, иконки, градиенты) не оценивалась: она задана китом BRICK, и в макетах она почти везде неверна (розовые фоны, Space Grotesk/засечки, моноширинный шрифт в S7/S10, карточки «в розовом»). Тип причины: **[норматив]** — WCAG 2.1/2.2 AA, документация продукта; **[данные]** — согласование с API; **[мнение]** — вкус UI-лида.

## Консенсус с API (be-lead)

Совместный блок, подтверждён be-lead (контракт `docs/api/admin.openapi.yaml`):

- **HAL.** Ресурсы `application/hal+json`, без HAL-FORMS. Кнопка = ссылка: действие есть ⇔ в `_links` ресурса или элемента коллекции есть `crane:<rel>`; href берётся из ссылки. Disabled с причиной — только `denied_actions` для выпуска токена, продвижения, запроса одобрения, удаления версии. Навигация — `GET /me` → `_links`.
- **Ошибки.** problem+json `{type, title, status, detail, reason, rule_id, request_id, remediation[], required_acr?}` без трассы; трасса — только `GET /diagnostics/{request_id}`. Скрытое и несуществующее — одинаковый **404** с нейтральным «Не найдено или нет доступа», без `rule_id`, `remediation`, `contact` и трассы (так же для чужого `request_id` в диагностике). **403** с `rule_id`, `request_id`, `remediation`, `contact` — только для видимого ресурса, где запрещено действие. Правка оркестратора при утверждении: опечатка в имени пакета не читается как «Недостаточно прав», и так же 404/403 понимают пакетные менеджеры.
- **Коллекции.** `_embedded` + `_links.next`, total нет; счётчики — отдельные агрегаты с `{count, capped}`.
- **Безопасность отображения.** Секрет только в 201 создания; журнал всегда маскирован, раскрытие — по одному событию с обоснованием ≥ 20 символов и MFA; «нет находок» — только при `scan`.
- **Живые данные.** Polling с ETag (30 / 15 / 60 / 30 / 60 с), пауза на скрытой вкладке и кнопкой.
- **Массовые действия.** `POST /vex-statements|/exceptions|/issues` со списком `finding_ids[]` → результаты по строкам; VEX — один advisory.

Отвергнуто вместе: SSE, единый 403 для скрытых (заменён единым 404 при утверждении), трасса в теле ошибки, точные total, отдельный suggest для палитры, единый уровень достоверности, bulk retry, HAL-FORMS, массив `allowed_actions`, `/findings/bulk/*`.
