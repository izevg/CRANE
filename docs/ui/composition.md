# Композиция: шелл, архетипы страниц, сетка, плотность

Документ задаёт каркас всех экранов веб-консоли CRANE. Визуальная система (цвета, шрифты, радиусы, тени, иконки) зафиксирована UI kit BRICK (`shared/styles/tokens.css`, `shared/ui/*`) и здесь не обсуждается. Здесь описано, **где что стоит и почему**.

Обозначения требований: **MUST** — инвариант (доступность, данные, безопасность, производительность), нарушать только с письменным обоснованием в отчёте fe-lead; **SHOULD** — рекомендация, подгоняется под стек без согласования; *мнение* — вкусовое решение UI-лида, помечено явно.

## 2. Сетка и ритм

- 12 колонок, гаттер 24 px (16 px ниже `lg`). Шаг отступов 4 px, ритм 8 px.
- Стандартные раскладки: **8/4** (основное + правая колонка), **12** (таблица на всю ширину), **3 × 4** (нижний ряд дашборда), **автосетка плиток** `repeat(auto-fit, minmax(200px, 1fr))` (5–6 плиток на 1440, 2 на телефоне).
- Правая колонка в 8/4 — это **справочная** информация (KeyValue, связанные сущности, сводки). Действия, без которых задача не решается, в неё не уходят. *Мнение:* правая колонка не длиннее основной, иначе она перестаёт читаться как справка.
- Порядок в DOM = порядок чтения = порядок фокуса. Правая колонка в DOM идёт после основной; ниже `xl` (1280) она встаёт под основную. MUST (WCAG 1.3.2, 2.4.3).

## 3. PageHeader и размещение действий

Анатомия (сверху вниз): h1 + StatusBadge (+ чипы формата/репозитория) → caption ≤ 72 знаков → ряд StatChip → line tabs.

Действия справа от h1:

1. **Одна primary** — главное действие страницы для текущей роли. Если главного действия без контекста нет (список находок без выделения, журнал), primary нет вовсе. Отклонено: «Принять VEX» как primary на S7 без выбранных строк, «Фильтры по умолчанию» primary на S9, «Выгрузить отчёт» primary на S6.
2. До **двух secondary**.
3. Остальное — в меню «…» (DropdownMenu). Опасные пункты в меню отделены разделителем и окрашены как destructive text.
4. Действия, требующие step-up, помечаются бейджем «MFA» на кнопке (идея из S9, сохраняем) и инлайн-уведомлением в диалоге.
5. Кнопка рендерится, только если в `_links` ресурса есть ссылка-действие `crane:<rel>`; href берётся из ссылки. Нет ссылки — **нет кнопки**. Disabled с подсказкой — только если API вернул `denied_actions` с причиной (например «Выпустить токен» при запрете долгоживущих токенов политикой). MUST: не показывать чужой роли «серую» кнопку её коллег (S4: владелец видит disabled «Одобрить продвижение (AppSec)» — отклонено).

## 4. Архетипы страниц

Каждый из ~60 экранов собирается из одного архетипа и набора паттернов (`patterns.md`).

### A. Страница-таблица (ref-01, S5, D3, E3, F6…)
PageHeader → (info-callout, если есть правило, которое пользователь должен знать) → строка фильтров → DataTable → «Загрузить ещё».
- Строка фильтров: поиск по списку → сегменты основного измерения со счётчиками → переключатели → select-ы → справа «Колонки», «Сбросить», подпись результата («1 000+ событий», `capped`).
- Фильтры, сортировка и вкладка — в URL (MUST: ссылкой можно поделиться, Назад возвращает состояние).
- Колонки имеют **приоритет**: 1 — всегда (первая колонка-идентификатор и колонка действий закреплены), 2 — с `lg`, 3 — с `2xl` и без открытой DetailPanel. Пользователь меняет набор кнопкой «Колонки» (есть в ките, ref-01); выбор хранится локально per-view. Горизонтальный скролл таблицы — последний резерв (таблица данных допускает двумерный скролл по WCAG 1.4.10), а не нормальный режим. В макетах S3, S7, S9 колонки обрезаны на 1440 — дефект, лечится приоритетами.
- Пагинация только курсором: «Загрузить ещё» = переход по `_links.next.href`. Никаких «1 / 3684», «Показано 5 из 18 420», внутренних курсоров на экране (S7 «cur_sec_890a21», S9 — отклонено).

### B. Карточка сущности (S2, S4, S8)
PageHeader с метриками-чипами → line tabs → сетка 8/4. Вкладка «Обзор» отвечает на главный вопрос роли (разработчик: как установить; AppSec: насколько плохо и что делать).
- Вердикт или блокирующее состояние — **callout сразу под вкладками**, до карточек (S3 панель, S4: «Продвижение заблокировано: 2 причины»). Сохраняем.
- Вкладки со счётчиками только там, где счётчик — сигнал к действию («Риски 1», «Находки 2»); «Файлы 1» — шум (*мнение*).

### C. Детальная панель (S3, S9, F8, E9)
Таблица слева, панель 560 px справа. Docked при ширине ≥ 1536 px, ниже — Sheet до 720 px поверх таблицы (правило кита). Отклонено: docked-панель на 1440 из макетов S3/S9, обрезающая таблицу.
- Анатомия: заголовок (идентификатор + StatusBadge + «…» + закрыть) → вкладки панели → содержимое → sticky footer с 1 primary + ≤ 2 secondary.
- Выбор строки = `?selected=<id>` в URL. Открытие переводит фокус на заголовок панели, Esc/закрыть возвращает фокус на строку (MUST, WCAG 2.4.3). Стрелки ↑/↓ в таблице при открытой панели меняют выбранную строку (SHOULD).
- «Открыть полностью» в меню панели ведёт на страницу-карточку (архетип B) с тем же содержимым.

### D. Дашборд (S6, F13, G1, I1, D5, C1)
PageHeader (h1 + бейдж режима + переключатель окна времени + «Пауза автообновления») → ряд MetricTile → сетка 8/4 (график | список состояния) → 8/4 (график | быстрые действия) → нижний ряд 3 × 4 сводок со ссылкой «Открыть …».
- Плитка — вход в отфильтрованный список, а не тупик: клик по «Очередь задач 42» ведёт в «Очереди» (SHOULD).
- MUST: одно значение — одно место. «Режим: норма» уже в topbar и бейдже h1; плитка «Системный статус: Норма» (S6) отклонена.
- Окно времени (1 ч · 6 ч · 24 ч · 7 дн) — сегменты в шапке, в URL.

### E. Очередь (S7, F8, F11, F12)
Это дашборд + таблица: баннер (если P0) → PageHeader → плитки-счётчики → фильтры → таблица с массовыми действиями; правая колонка с «сводками соседних очередей» (экстренные блокировки, фиды, лицензии).
- Правая колонка показывается рядом с таблицей только с `2xl`; ниже — под таблицей. Таблица важнее (это работа, колонка — контекст).
- Сортировка по умолчанию: приоритет ↓, затем срок SLA ↑.
- Новые строки при автообновлении не вставляются под курсор: появляется пилюля «Новых: 3 · Показать» над таблицей (MUST: не сдвигать содержимое, на котором стоит фокус; WCAG 2.2.2/3.2.5 по духу, INP).

### F. Журнал (S9, D2, H1, G2)
Как A, но фильтры шире (две строки допустимы), первая колонка — время UTC с миллисекундами, плотные моноширинно-подобные данные — табличные цифры. Над фильтрами — постоянная заметка, что поиск журналируется (`audit.viewed`). Для SecOps над фильтрами ряд из 4 плиток (события, отставание SIEM, цепочка, якорь WORM) — идея S9, сохраняем, но только для SecOps; аудитор видит плитку цепочки, без отставания SIEM.

### G. Мастер (E11 импорт, D4 редактор политики доверия при первом создании)
Stepper (номер + название шага + состояние) → карточка шага → sticky-подвал «Назад / Далее». Шаги идемпотентны и возобновляемы: состояние в URL и на сервере. MUST: Назад не теряет введённое (WCAG 3.3.7 Redundant Entry).

### H. Чат (J2)
Колонка 880 px по центру, композер прибит к низу, пустое состояние — примеры-чипы (ref-09). Ответ ассистента — с цитатами; «Шаги» (вызовы инструментов) свернуты.

### I. Результаты поиска (S1, B2)
Поиск + кнопка → сегменты форматов со счётчиками → вторичные фильтры → 8/4: список карточек-результатов | фасеты. Ниже `xl` фасеты сворачиваются в кнопку «Фильтры» над списком (Sheet).

### J. Форма настроек (ref-07, E3 «Настройки», F10)
Карточки-секции с h2 → поля «лейбл над полем, единица справа, подпись под полем» → StickySaveBar появляется при изменениях. Изменения политик безопасности: перед сохранением обязательный Diff и комментарий (F9, F10).

### K. Отдельная страница подтверждения (A1, J3)
Без шелла, карточка по центру ≤ 28 rem, одно решение, срок действия видимым таймером.

## 5. Плотность

- Строка таблицы 44 px, шапка 40 px, без зебры. Плитка 112–132 px по высоте. Карточка: внутренний отступ 16 (20 с `sm`).
- *Мнение:* одна строка таблицы = одна строка текста. Многострочные ячейки (скоупы токена в S5, переносы имён в S8) — дефект: длинные множества сворачиваются в «read: все · publish: 2» + Popover со списком.
- Максимум 2 строки в ячейке: значение + caption (CVE + алиас, пакет + версия).
- Числа справа, табличные цифры; идентификаторы — CopyableId с усечением в середине.

## 6. Адаптивность

| Ширина | Что меняется |
| --- | --- |
| ≥ 1536 (`2xl`) | DetailPanel docked; правая колонка очереди рядом с таблицей; колонки приоритета 3 видны |
| 1280–1535 (`xl`) | Панель — Sheet; 8/4 сохраняется |
| 1024–1279 (`lg`) | 8/4 → одна колонка; плитки 3 в ряд |
| 768–1023 (`md`) | Сайдбар свёрнут до 64 px; фасеты поиска в Sheet |
| < 768 | Сайдбар — Sheet; таблицы показывают колонки приоритета 1 + раскрытие строки; BulkActionBar на всю ширину |
| 320 | MUST: без горизонтального скролла страницы (WCAG 1.4.10), кроме области таблицы |

MUST: зум 200 % на 1280 работает как вёрстка `md`/`lg` без потери функций (WCAG 1.4.4). Контрольные точки — по контенту (ширина таблицы), а не по устройствам.

## 7. Живые данные

Каденсы согласованы с API (polling с ETag/304, без SSE): статус и баннеры 30 с; плитки и компоненты S6 15 с; графики 60 с; сводка находок 30 с; уведомления 60 с. Опрос останавливается на скрытой вкладке и кнопкой «Пауза автообновления» (AutoRefreshToggle из кита).

- MUST: обновление данных не перемещает фокус и не перестраивает строку, на которой стоит фокус или курсор.
- MUST: изменения, важные для пользователя (новый P0, сбой upstream), объявляются через live region `polite` один раз; рядовые обновления чисел — молча.
- SHOULD: подпись «Обновлено 12 с назад» (RelativeTime) у каждого блока с живыми данными; при ошибке опроса — «Не удалось обновить · Повторить», последние данные остаются на экране с пометкой времени.
- Отклонено: анимированный счётчик чисел (NumberTicker) на живых плитках — отвлекает и мешает чтению; допускается только при первом появлении, с `prefers-reduced-motion` — без анимации.

## 8. Фокус и навигация

- Смена маршрута: фокус на h1, объявление заголовка страницы (MUST, SPA).
- Skip-link «К содержимому» (MUST, 2.4.1).
- Открытие Dialog/Sheet: фокус на первое поле или, для деструктивного подтверждения, на «Отмена»; закрытие возвращает фокус на триггер.
- Sticky-элементы (topbar, sticky footer панели, BulkActionBar, StickySaveBar) не перекрывают элемент в фокусе: `scroll-padding` на величину sticky-зон (MUST, WCAG 2.2 2.4.11).

## 9. Движение

Только по токенам кита: вход 200 мс ease-out `cubic-bezier(.23,1,.32,1)`, выход 150 мс, Sheet 250 мс `cubic-bezier(.32,.72,0,1)`; только `transform` и `opacity`; stagger ≤ 8 элементов по 40 мс; пульс статуса 1.6 с × 3. `prefers-reduced-motion: reduce` → фейды 150 мс без сдвигов, пульс выключен. Графики не анимируют перерисовку при каждом опросе (MUST: иначе это автодвижение каждые 15 с).
