# Лицензия

**Русский** · [English (LICENSE)](../LICENSE)

CRANE распространяется по лицензии **Apache License, Version 2.0**. Юридическую силу имеет только английский текст в файле [`LICENSE`](../LICENSE); этот документ — неофициальное краткое изложение для удобства и не заменяет лицензию.

## Коротко

| Можно | При условии | Нельзя |
| --- | --- | --- |
| Использовать в коммерческих и некоммерческих целях | Сохранять уведомления об авторских правах и текст лицензии | Использовать товарные знаки и название проекта для продвижения своего продукта без разрешения |
| Изменять и создавать производные работы | Отмечать в изменённых файлах, что они изменены | Требовать от авторов гарантий и возмещения ущерба |
| Распространять в исходном и бинарном виде | Передавать содержимое файла [`NOTICE`](../NOTICE), если он есть | |
| Включать в проприетарные продукты | | |
| Пользоваться патентами участников на их вклад | Не подавать патентных исков к проекту: при иске патентная лицензия прекращается | |

## Почему Apache-2.0

- Явный патентный грант от каждого участника защищает пользователей.
- Совместима со всем стеком CRANE: в поставку входят только компоненты под MIT, Apache-2.0, BSD, ISC и сходными пермиссивными лицензиями (см. [раздел 17](product/17-oss-stack-licenses.md)).
- Вклад в проект принимается на условиях той же лицензии (раздел 5 лицензии) с подписью DCO, см. [CONTRIBUTING.md](../.github/CONTRIBUTING.md).
