# 15. Frontend и опыт ролей

SPA на React строится на собственном UI kit на Base UI: дизайн-токены, таблицы с виртуализацией, диффы, JSON-просмотрщик, метрики, чат-компоненты с цитатами для AI-функций. Сборка встраивается в бинарник, отдельный веб-сервер не нужен.

## Структура кода: FSD и правило четырёх

Код `web/src/` организован по Feature-Sliced Design: слои `app → pages → widgets → features → entities → shared`. Импорт идёт только вниз, слайсы одного слоя не импортируют друг друга, слайс доступен только через публичный API (`index.ts`). Это проверяют Steiger (структура FSD) и dependency-cruiser (направление импортов и циклы); knip ловит неиспользуемый код и зависимости, Biome отвечает за формат и линт.

Поверх FSD действует «правило четырёх» ([раздел 8](08-c4-l4-code.md)): не больше 4 файлов и 8 подпапок в папке, смешанные папки запрещены. Сегмент слайса (`ui`, `model`, `api`), который перерос лимит, делится на подпапки по смыслу. Семь слоёв FSD укладываются в лимит подпапок.

## Рабочие столы ролей

| Роль | Главный экран | Ключевые действия в один клик |
| --- | --- | --- |
| Разработчик | Поиск, избранное, недавние; карточка пакета с командой установки под выбранный клиент | Скопировать команду, посмотреть замену deprecated |
| Владелец библиотеки | Мои пакеты: версии, здоровье, потребители, открытые риски | Deprecate, назначить замену, запросить approval |
| CI/CD-инженер | Роботы, trust policies, последние публикации из CI, ошибки | Создать trust policy, выдать шаблон CI |
| Platform admin (DevOps) | Хранилища и классы хранения, объём по командам, cache hit, upstream, очереди, бэкапы | Dry run retention, прогрев, проверка целостности |
| AppSec | Очередь P0–P4 с оценками systemone и факторами, SLA, экстренные блокировки, состояние фидов, лицензии на review с оценкой вирусности | Подтвердить экстренную блокировку, принять VEX, выдать исключение с TTL, создать задачи |
| SecOps | «Журнал действий»: поиск, маскированные данные, раскрытие с обоснованием, экспорт, проверка целостности; события SIEM, нарушения разделения обязанностей, активные экстренные блокировки | Раскрыть данные события, выгрузить диапазон, отозвать токен |
| Аудитор | Журнал действий только на чтение с маскированными данными, отчёты о соответствии | Сформировать отчёт |
| Любой пользователь | «Мои токены» и «Мои действия» | Отозвать токен, посмотреть свою историю |
| Руководитель | Владение, доступы команды, риски, потребление ресурсов | Экспорт отчёта |

## Требования к отзывчивости

-   Поиск p95 меньше 150 мс на сервере; результаты по мере ввода с debounce 150 мс.
-   Списки любого размера с виртуализацией; prefetch карточки по наведению.
-   Первая загрузка SPA меньше 250 КБ gzip, остальное лениво по маршрутам.
-   Доступность WCAG 2.2 AA (контрасты уже заложены в токенах кита), светлая и тёмная темы.
-   Интерфейс на русском и английском (RU/EN) обязателен: нет захардкоженных видимых строк, язык переключается в самом интерфейсе.
-   Командная палитра (Ctrl K: переходы и поиск пакетов по ссылкам из `GET /me`) и центр уведомлений (те же события, что уходят в почту и вебхуки) — с первой версии UI.
-   Композиция, паттерны и экраны — [docs/ui/](../ui/README.md); контракт данных — `docs/api/admin.openapi.yaml`.

## Безопасность отдачи

README, metadata и evidence пакетов недоверенны (14.3), поэтому консоль работает со строгой политикой.

-   **CSP консоли:** `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'`.
-   **Заголовки:** `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`, `Cross-Origin-Opener-Policy: same-origin`.
-   Inline-скриптов и `unsafe-eval` нет; исключение требует отдельного решения.
-   **README:** react-markdown + rehype-sanitize. Сырой HTML не пропускается (`rehype-raw` запрещён). Внешние картинки не загружаются, а показываются ссылкой: иначе пиксель слежки следил бы за AppSec и SecOps; политика `img-src` это обеспечивает. Ссылки получают `rel="noopener noreferrer nofollow"`, iframe и формы вырезаются.
