# 11. Эвристики

Эвристики настраиваются в конфигурации репозитория. Значения ниже являются стартовыми и корректируются по метрикам эксплуатации.

## 11.1 TTL proxy-кэша

| Объект | TTL | stale-while-revalidate | Negative TTL | stale-if-error |
| --- | --- | --- | --- | --- |
| Архивы и файлы (все форматы) | ∞ (неизменяемы, ключ по пути и digest) | — | 5 мин | — |
| npm packument | 5 мин | 5 мин | 1 мин | 7 дней |
| PyPI Simple API | 10 мин | 10 мин | 2 мин | 7 дней |
| Maven metadata release | 6 ч | 6 ч | 10 мин | 7 дней |
| Maven SNAPSHOT metadata | 1 мин | 1 мин | 1 мин | 1 день |
| NuGet registration и flat container index | 10 мин | 10 мин | 2 мин | 7 дней |
| Cargo sparse index (файл крейта, `config.json`) | 5 мин, условные запросы по ETag | 5 мин | 1 мин | 7 дней |

-   **Что считается сбоем для stale-if-error.** Колонка относится к 5xx, таймаутам и сетевым сбоям. Ответы 410 и 451 означают удаление (в том числе по закону): они обрабатываются как 404, то есть кладут отрицательную запись и stale не отдаётся; исходный статус остаётся в журнале egress, чтобы `SecOps` отличал снятие по закону от обычного 404. Ответы 429 и 403 означают, что upstream отказывается нас обслуживать (rate limit, блокировка WAF или IP; снятие пакета приходит как 404/410/451): stale отдаётся не дольше 24 ч после истечения TTL и не дольше stale-if-error формата, метка `upstream_failure="throttled"`. Иначе атакующий, спровоцировав rate limit, заморозил бы документы на неделю.
-   **Адаптивный TTL**: если metadata не менялась N = 3 (настраивается) обновления подряд, TTL удваивается до верхней границы (×8); при изменении сбрасывается.
-   **Refresh-ahead и stale-while-revalidate**: любой запрос в последних 10% TTL запускает фоновое обновление (одно на ключ благодаря singleflight); окно stale-while-revalidate продолжает ту же зону после истечения TTL. Счётчик частоты по ключу виден реплике лишь на долю трафика, обратную числу реплик, а цена для холодного ключа — один условный запрос, обычно 304, за период TTL.
-   **Отрицательный кэш с ростом**: повторные 404 одного ключа удваивают negative TTL до 1 часа. Это защищает upstream от опечаток в CI.
-   **Cache-Control upstream** (`s-maxage`, иначе `max-age`, за вычетом заголовка `Age`) продлевает TTL документа, но не выше адаптивного потолка ×8 и не ниже настроенного TTL: срок = max(TTL·2^k, min(max-age, TTL·8)). При `no-cache`, `no-store` и `private` подсказка не действует: proxy-реестр подтверждает документы по ETag. Ответ 304 обновляет подсказку. Артефакты и 404 Cache-Control не учитывают.

## 11.2 Доставка blob

-   Файлы меньше 1 МБ отдаются потоком через API server (меньше задержка, единая точка контроля).
-   Файлы больше порога в профиле L отдаются presigned redirect на S3 с TTL 60 с, если клиент поддерживает redirect (npm, pip, Maven, NuGet, Cargo поддерживают). Авторизация всё равно проходит в CRANE, обхода proxy нет.
-   Сжатие ответов только для metadata; архивы не сжимаются повторно.

## 11.3 Определение лицензии

-   Совпадение текста license-файла с шаблоном SPDX ≥ 0.9 даёт определение, 0.75–0.9 даёт «вероятно X, нужна проверка», ниже 0.75 даёт Unknown.
-   Расхождение между заявленной в metadata и найденной в файле лицензией помечается как конфликт, даже если обе разрешены.
-   Устаревшие идентификаторы (`GPL-2.0` без `-only`/`-or-later`) нормализуются с пометкой «неоднозначно».

## 11.4 Ранжирование поиска

| Сигнал | Множитель |
| --- | --- |
| Пакет принадлежит workspace пользователя | ×1.15 |
| Скачивания за 30 дней | ×(1 + 0.05·ln(1 + n)) |
| Есть README и владелец | ×1.10 |
| Последний релиз старше 2 лет | ×0.85 |
| Deprecated / EOL | ×0.30, с показом рекомендованной замены |
| Открытая critical CVE в последней версии | ×0.80, с бейджем |
| Точное совпадение имени | всегда первая позиция |

## 11.5 Прочие эвристики

| Задача | Эвристика |
| --- | --- |
| Поиск дубликатов библиотек | Косинусная близость эмбеддингов README и описания ≥ 0.88 и пересечение ключевых зависимостей ≥ 50%; результат показывается как кандидат на проверку, а не вердикт. |
| Typosquatting в proxy | Имя на расстоянии Дамерау–Левенштейна 1 от популярного пакета или внутреннего имени при малом числе скачиваний upstream даёт предупреждение в карточке. |
| Неиспользуемые credentials | Не использовался 30 дней: уведомление владельцу; 90 дней: предложение отозвать; за 14 и 3 дня до истечения: напоминание. |
| Устаревший отчёт сканирования | Отчёт старше текущей базы больше чем на 24 ч или SBOM старше 30 дней помечается «неактуален». |
| Очистка SNAPSHOT | Хранить 5 последних timestamp-сборок и всё, что скачивалось за 14 дней. |
| Приоритет в очереди задач | Задачи, блокирующие promotion, выше фоновых пересканов; внутри класса FIFO с весом по размеру. |
| Подозрительная публикация | Новая версия с резким ростом размера (×5), новыми install-скриптами npm или бинарниками в sdist получает пометку для security review. |
| Очистка логов для AI | Регулярные выражения известных форматов токенов, URL с userinfo, заголовки Authorization, плюс энтропия Шеннона больше 4.0 на строках длиннее 20 символов. |
